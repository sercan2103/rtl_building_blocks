# RTL Building Blocks

A collection of small, self-contained RTL blocks written in Verilog. Each block lives in its own folder with its RTL, cocotb testbenches and a short README.

## Blocks

| Block | Description |
|---|---|
| [`uart/`](uart/) | UART transmitter, receiver and loopback |
| [`common/`](common/) | Shared modules (synchronizer) |

## Tools

- Icarus Verilog
- cocotb (Python)
